# Toki

**코딩 에이전트를 쓰면 자라는 데스크톱 다마고치.**

바탕화면 한구석에 작은 CRT 모니터가 있습니다.  
Claude Code나 Codex와 같은 코딩 에이전트로 일하면 그 안의 펫이 조금씩 자랍니다.  
옆에는 포스트잇을 붙여두고, 배터리 게이지로 남은 사용량을 볼 수 있습니다.  
펫에게 지난 한 달을 훑어보고 "이건 스킬로 만드는 게 낫겠어요" 같은 제안을 받을 수 있습니다.

## 설치

터미널 한 줄이면 됩니다.

**macOS** (터미널)

```sh
curl -fsSL https://toki.dkdk.me/install.sh | bash
```

**Windows** (PowerShell)

```powershell
irm https://toki.dkdk.me/install.ps1 | iex
```

먼저 읽어보고 실행하고 싶다면:

```sh
curl -fsSL https://toki.dkdk.me/install.sh -o install.sh
less install.sh && bash install.sh
```

`.dmg`(macOS)나 `setup.exe`(Windows)를 직접 받아도 됩니다 → [releases](https://github.com/Daekyo-Jeong/toki/releases/latest)

> **왜 터미널을 권하나**: macOS는 브라우저로 받은 파일에 격리 딱지를 붙입니다.
>
> `curl`로 받으면 그 딱지가 안 붙어서 "손상되었기 때문에 열 수 없습니다"를 아예
> 만나지 않습니다.  
> dmg도 Apple 공증을 받았으니 경고 없이 열리지만, 터미널 쪽이
> 한 단계 적습니다.

**필요한 것**


|       |                                                                                                                    |
| ----- | ------------------------------------------------------------------------------------------------------------------ |
| macOS | 11 이상 · **Apple Silicon**                                                                                          |
| Windows | 10 이상 · x64 · 훅·사용량 연동에 [Git for Windows](https://git-scm.com/downloads/win) (Claude Code가 Git Bash로 실행) |
| 에이전트  | [Claude Code](https://claude.com/claude-code) 또는 [Codex CLI](https://developers.openai.com/codex/cli) — 둘 다 써도 됩니다 |

인텔 맥은 지원하지 않습니다. Windows 설치 파일은 아직 코드 서명이 없어 SmartScreen 경고가 뜹니다 — "추가 정보 → 실행"으로 넘어가면 됩니다.


처음 켜면 어떤 에이전트가 설치 되어 있는지 찾아서 보여주고, 기록을 읽어 그동안 쌓인만큼 레벨을 매깁니다.

## 데이터에 관하여

- **수집 서버가 없습니다.** 텔레메트리도, 분석도, 크래시 리포트도 없습니다.
- **데이터 저장은 전부 개인 컴퓨터 경로**, `~/.toki/` 입니다.
- **네트워크는 두 경우에 필요합니다.** 하나는 업데이트가 있는지 확인할 때, 다른 하나는 **코칭 버튼을 눌렀을 때**입니다.
- 자격증명을 갖지 않습니다. 코칭은 이미 로그인해둔 `claude`/`codex`를 그대로
빌려 씁니다.

코칭을 누르면 최근 30일 프롬프트 원문, 만들어둔 스킬·커맨드 목록, `CLAUDE.md`  
같은 규칙 파일, 그리고 개인 지속 기억이 **본인이 구독/선택중인 CLI를 통해** 모델로 갑니다.  
적지 않은 양입니다. 실행 화면의 "고지" 버튼에 그때그때 나가는 목록이 그대로 나옵니다.

아무것도 내보내고 싶지 않다면 코칭을 이 컴퓨터 안에서 돌릴 수 있습니다 →
[코칭과 쿼터](#코칭과-쿼터)

## 뭘 하나

**펫이 자랍니다.** 토큰 사용량이 곧 경험치입니다. 레벨이 오르면 새 펫이 열리고,
12종 중에 골라 쓸 수 있습니다.  
허기 게이지는 남은 사용량이라, 배터리가 줄면
그만큼 오늘 많이 썼다는 뜻입니다.

**메모를 붙입니다.** 셸 위쪽 메모지 뭉치를 누르면 포스트잇이 한 장 떨어집니다.

체크리스트로 쓰거나 그냥 적어두거나. 모니터를 여러 대 쓴다면 화면 사이로 끌어
옮길 수 있고, 모니터를 뽑아도 사라지지 않습니다.

**코칭을 받습니다.** 눌렀을 때만 돕니다. 자동으로 도는 일은 없습니다.

반복되는데 아직 자산이 안 된 것을 찾아 줍니다.  
같은 지시를 세 번 이상 하면 커맨드로, 같은 교정이 기억에 네 번 쌓였다면 스킬로.

실제로 이런 말을 합니다.

![코칭 결과 예시](./toki_coaching.png)

**뽀모도로도 있습니다.** 집중하는 동안 펫이 같이 화면을 봅니다.

**펫을 직접 만들 수도 있습니다.** [Toki Studio](https://toki.dkdk.me/studio)에서
픽셀을 찍어 자기 펫을 그리고, 내보낸 파일을 `~/.toki/pets/` 에 넣으면 외형
목록에 함께 뜹니다. 기본 12종과 달리 **해금 조건이 없어서** 만들자마자 쓸 수
있습니다. 숨쉬기나 배고픔 같은 상태별 움직임도 프레임으로 넣을 수 있습니다.

## 코칭과 쿼터

코칭은 본인의 구독 쿼터를 씁니다. 사용량을 재는 앱이 사용량을 만드는 셈이라,
규칙을 두었습니다.

- **버튼을 누를 때만** 돕니다. 주기 실행도, 자동 실행도 없습니다.
- 실행 전에 **어느 쿼터를 얼마나 쓰는지** 화면에 적습니다.
- 알림과 넛지는 LLM을 안 씁니다. 전부 규칙 기반입니다.

설정 → 코칭 LLM에서 고를 수 있습니다.


| 값                  | 뜻                       |
| ------------------ | ----------------------- |
| `AUTO` (기본)        | 최근에 쓴 에이전트를 따라갑니다       |
| `CLAUDE` / `CODEX` | 고정                      |
| `LOCAL`            | Ollama — 쿼터 0, 밖으로 안 나감 |


**개인 토큰을 쓰고 싶지 않다면 `LOCAL`입니다.** [Ollama](https://ollama.com)가 이
컴퓨터 안에서 답합니다. 품질은 떨어지지만 아무것도 나가지 않습니다.

## 저장 위치

전부 `~/.toki/` 아래입니다.


| 파일              | 설명                          |
| --------------- | --------------------------- |
| `engine.sqlite` | 사용 기록과 성장 상태                |
| `desk.json`     | 메모와 셸 위치                    |
| `memory.md`     | 붙여넣은 기억 (있을 때만)             |
| `pets/`         | Studio에서 만든 펫               |
| `prompts/`      | 코칭 지시문 — 고쳐 쓰면 다음 실행에 반영됩니다 |
| `coaching/`     | 코칭 결과 보관                    |


지우고 싶으면 이 폴더를 지우면 됩니다.
